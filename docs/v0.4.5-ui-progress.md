严格复刻指定的 EdenVoice v0.4.5 原型图，并保持现有语音、音频设备与网络模式功能可用。

# Frozen

- 音频采集与播放
- Opus 编解码
- VAD / PTT
- AEC / AGC / RNNoise / DeepFilterNet
- Runtime Device Switching

# Accepted

- 客户端 UI 已迁移为 Slint，不再以 egui 实现目标界面。
- macOS 默认模式窗口比例、196px 左栏、Header 与 45px 底栏几何已通过实际截图验证。
- 房间网络模式卡片的单选圆点居中，标题与说明文字不再裁切。
- 音频设置继续绑定真实输入/输出设备、采样率、增益、降噪、AEC、AGC 与测试功能。
- 连接页支持保存服务器档案、历史直连和编辑显示名称/地址/加入昵称。
- 服务端配置的 `server_name` 已在现有 Welcome/ServerState 链路中下发，并由客户端写入历史。
- 左上服务器选择器已绑定保存列表和真实切换回调。
- 紧凑模式已移除重复服务器行，使用独立频道模型，并支持当前频道横向头像预览与 `+N` 聚合。
- 拓扑 Badge 已改为内嵌实色矢量标志，修复图标凸出边框的问题；默认模式底栏右侧留白已增加。
- 连接页“记住我”已从字符勾改为 Lucide 风格矢量勾，并真实控制是否写入服务器历史。
- 左下临时频道入口已改为原型式浅灰图标按钮；后端未实现前保持明确禁用。
- 当前协议没有文字消息类型，输入区已明确标注“文字消息暂未开放”，不再伪装成可输入控件。
- 频道/用户右键菜单与用户信息卡已完成首版；加入频道、静音频道和本地静音用户使用真实回调，权限管理类操作明确置灰。
- 根据首轮菜单截图移除了原型中不存在的频道/用户标题行，压缩菜单宽度与行高；用户信息卡缩至 220×276，并恢复原型的双状态图标底栏。
- 本地静音用户和静音频道现在会在默认频道树、默认成员区与紧凑成员区显示真实 `volume-off` 状态。
- 默认模式右侧已按原型改为消息流式层级（头像、名称、时间与状态正文），内容仅映射真实成员语音状态。
- 菜单、用户信息卡、网络详情、服务器编辑和设置弹窗已统一补充克制的柔和阴影。
- 客户端包版本已同步到 `0.4.5`。
- 新增可重复的无头 UI 预览工具，可输出默认、紧凑、菜单、用户卡、成员列表、网络详情及各设置页截图。
- 默认频道树移除多余行间距，修复底部频道与临时频道入口被裁切；不可用入口与搜索/收藏均明确置灰。
- 网络详情收口为原型式轻量浮层；房间网络设置收口为独立紧凑卡片，不再占满设置窗口。
- 快捷键页已实现；`Ctrl/Cmd+B`、`Ctrl/Cmd+M`、`Ctrl/Cmd+Shift+S` 与 `Ctrl/Cmd+U` 均连接真实界面操作，PTT 显示真实配置按键。
- 默认模式新增真实成员列表浮层，并与顶栏/频道标题成员按钮和 `Ctrl/Cmd+U` 绑定。
- UI 预览支持原生窗口自截图；已使用 macOS 系统字体与 2× HiDPI 原生渲染逐项校准默认和紧凑模式。
- 原生截图校准后下调顶栏、频道标题、消息流和紧凑成员列表的视觉字号与头像尺寸，保留原按钮命中区。

# Do Not Reopen

- 不再讨论是否继续使用 egui：目标实现固定为 Slint。
- 不使用字符或 Emoji 充当功能图标；当前图标采用 Lucide 风格矢量 Path，并保留 MIT 许可证。
- RNNoise 与 DeepFilterNet 的强度固定显示为自动，不增加伪造强度选项。
- 房间网络模式保留自动、强制 SFU、强制 P2P 三种真实策略。
- 简/大窗口切换支持界面菜单与原型中的 `Ctrl/Cmd+B` 快捷键。
- 用户已明确要求砍掉迷你悬浮窗：不保留入口、组件、回切逻辑或隐藏实验代码。
