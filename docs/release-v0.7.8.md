# v0.7.8 发布准备

- 客户端、服务端以及应用内版本号统一为 0.7.8。
- 新的双叶声波 Logo、明暗主题应用图标和专用托盘图标；产品页与管理后台同步品牌资源。
- 从 0.7.6 升级包含 0.7.7 的语音收件人索引、发送缓冲复用、客户端快照增量及静音处理优化。

## 发布顺序

1. 将 `dist/v0.7.8/upload-to-cos/releases` 上传到桶根目录，保持目录结构。
2. 核验各平台的安装包、自动更新包已可访问，签名与文件匹配。
3. 使用 `dist/v0.7.8/后台填写模板` 的平台、版本、URL、签名与说明，在管理后台保存草稿后确认发布。
4. macOS 初次安装用 DMG，自动更新必须使用 `EdenVoice.app.tar.gz`；Windows 使用 EXE，Linux 使用 AppImage。
5. 产品页通过 releases.json 读取版本和五个安装包 URL，已切换为 0.7.8。未来只需替换该 JSON。

服务器后台发布的是客户端更新公告，不会自动升级服务器程序。服务器程序如需更新，另行部署对应 CPU 架构的服务端包并保留已有配置、身份和数据。

0.7.6/0.7.7 客户端连接发布服务器后提示 0.7.8；已安装 0.7.8 的客户端不会重复更新。未配置的平台不下发更新。上传与构建不等于发布后台公告；后台客户端更新仍由管理员分别确认发布。本轮按用户授权推送版本标签并部署服务端及产品页。

- Windows x64 NSIS、macOS Apple Silicon DMG / app.tar.gz、Linux x64 AppImage，以及 Linux AMD64 / ARM64 服务端包均已生成。
- 客户端核心测试 244 项通过、1 项忽略；桌面 Rust 测试 32 项通过；服务端测试及 go vet 通过。
- 更新确认、延后安装、通话中二次确认和静默失败的浏览器测试通过。
- 三个平台更新包均使用客户端内置公钥验签通过，上传清单 SHA-256 与后台模板路径/签名一致。
- macOS 应用签名检查和内置版本检查通过；Windows 主程序为 x64、版本资源为 0.7.8；两种 Linux 服务端实际运行 `--version` 均为 0.7.8。
- Linux 完整打包期间修复托盘图像所有权问题，以及 macOS Bash 3 空数组启动构建容器的兼容问题。
- Windows / Linux 桌面实机通话和从 0.7.6 原地升级仍需实际设备验收。本次未自动安装到用户当前客户端。
