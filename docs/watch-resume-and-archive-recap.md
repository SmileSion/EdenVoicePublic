# 观影续播与 Archive 回顾卡片

## 观影恢复进度

客户端本机保存最多 100 条进度，按服务器、频道、影片名称、文件大小和时长区分；不读取或上传影片内容。每 5 秒保存一次，并在离开页面时尽力保存，异常退出最多可能丢失最近 5 秒。不同版本的影片不会仅凭名称套用进度。

主持人重新加载同一影片，且当前房间暂停、进度在开头时，可以选择“恢复全员进度”。确认只跳转，不自动播放；其他成员仍通过既有观影同步机制跟随。普通成员加入正在进行的观影时以房间进度为准。开头不足 10 秒、距片尾不足 15 秒的记录不提示续播。清除客户端网站数据也会清除书签；本功能不跨设备同步。

## Eden Archive 回顾卡片

频道菜单 → 查看 Eden Archive → 制作回顾卡片。可选择房间总体回顾或当前已加载的具体纪念事件，预览后保存 PNG。事件卡片下方统计明确标为房间累计，并非该事件当时的历史快照。全部记录开关可加载更多可选事件，仍遵循现有服务端响应容量限制。

默认隐藏房间名称；可选显示所选回忆参与成员的昵称，默认开启；没有昵称则跳过，不使用 Client ID 替代。最多展示 6 个昵称，更多成员缩略为人数。总体回顾只使用当前已加载回忆中的成员，非全量历史成员名录。图片不含服务器地址、成员 ID、聊天正文。没有后台发布或自动分享。图片由本机 Canvas 生成，原生客户端使用保存对话框，取消不会写文件。统计来自真实 Archive 数据；未开启 Archive 的服务器不显示制卡入口。

## 验证

- `npm --prefix desktop run build`
- `cargo check --manifest-path desktop/src-tauri/Cargo.toml`
- `node --test desktop/scripts/watch-progress.test.ts`
- `node desktop/scripts/watch-party.test.mjs`（需 Playwright / Chrome）
- `node desktop/scripts/archive-recap.test.mjs`（需 Playwright / Chrome）

浏览器测试使用显式模拟的原生桥，验证主持人确认前不跳转、确认后不自动播放、卡片预览与 PNG 导出一致。真实 mpv 多客户端和各平台系统保存对话框仍需发布前人工验收。
