# Windows 游戏状态识别

## 使用

需要同时更新客户端和服务器。在「设置 → 个人资料 → 游戏状态」打开「共享正在玩的游戏」。新配置默认开启，已有用户保留自己的选择；修改立即保存，无需再点底部保存。Windows 上开启且连接到支持 `game_activity_v1` 的服务器后才枚举进程；macOS/Linux 可以接收和展示朋友状态，但不能开启 Windows 检测。

游戏夜场景的成员状态显示游戏名称。退出游戏通常在 5 秒内清除，关闭分享立即提交清除。断线后状态随会话移除；停止刷新时服务端 60 秒过期（清理间隔 5 秒），界面同样检查过期时间。

## 识别范围

初始目录为 `server/internal/protocol/game_catalog.json`。新版管理端可以维护并发布目录，无需为规则更新重装客户端。第一版包含 CS2、Dota 2、英雄联盟、无畏契约、PUBG、Apex Legends、守望先锋、Fortnite、原神、崩坏：星穹铁道、艾尔登法环、博德之门 3、绝地潜兵 2、Minecraft 基岩版、Terraria、星露谷物语。

按可执行文件基名精确匹配，忽略大小写。不是所有游戏自动支持；新游戏或更名后的 executable 由 MASTER / 服务器管理员在管理端发布目录。Java 版 Minecraft、通用 javaw.exe、Steam/其他启动器不会直接识别为游戏。多个游戏同时运行时优先前台匹配，其次保留当前仍运行的游戏，最后选目录顺序中的匹配项。最小化/切回客户端不会立即丢失仍运行的游戏。

## 数据和性能

使用 Windows [Tool Help API](https://learn.microsoft.com/en-us/windows/win32/api/tlhelp32/nf-tlhelp32-process32firstw) 枚举 PID 和可执行文件基名，仅在内存中匹配；不读取命令行、进程内存、窗口标题，不注入、不申请管理员权限，也不上传完整进程列表或路径。可执行文件名匹配并非防伪认证，只用于社交状态。

独立检测线程每 5 秒扫描，核心线程只读取一份可替换结果，不等待检测锁。关闭/重连使用代次标识拒绝旧结果。识别变化立即上报，未变化的活跃游戏每 20 秒续期。发送使用现有有界控制队列的非阻塞写入，不接触音频处理路径。

请求 `set_game_activity` 只含 `game_id`，空字符串表示清除。服务端从认证连接确定会话，自行生成名称、来源和时间；未知标识拒绝，非空更新每会话至少间隔 3 秒，清除不受此限制。状态不持久化。

成员快照增加可选 `game_activity`，实时变化复用 `user_state_changed`，带完整既有静音字段以及活动对象或 null，兼容旧客户端忽略额外字段。新客户端通过服务端功能声明避免向旧服务器发送新命令。

## 动态目录与自动场景

管理端「游戏识别」支持添加游戏、修改名称、多个进程文件名、启停、保存草稿、预览差异并发布、回退上一发布版。无游戏图标。游戏 ID 在编辑表单中固定。限制最多 64 款、每款 8 个精确进程名、整体 24 KB；禁止路径、通配符、通用解释器与启动器。服务端和客户端各自校验整份目录。

`game-catalog.json` 位于现有服务端 data_dir。草稿 / 发布 / 上版持久化为同一原子替换文件，版本单调递增；revision 冲突拒绝覆盖其他管理员变更。发布和回退记入现有审计日志。只读 Web 账号不能修改，频道管理员不能管理目录。

功能声明 `game_catalog_v1`、`auto_room_scene_v1`。`server_state.game_catalog_version` 通知版本，客户端按需请求 `get_game_catalog`，服务端只给请求者返回 `game_catalog`。常规快照不包含完整目录。拉取失败每 10 秒重试，同一服务器地址和指纹保留最近有效目录的进程内缓存（最多 32 个服务器）；没有有效目录时等待下载，不跨服务器使用缓存。旧服务器使用内置目录；新协议命令有独立功能门控。

目录更新触发独立检测线程重新识别。游戏停用会立即清除服务器成员状态与对应场景，改名立即更新展示。不会替用户开启共享。检测锁只用于交换不可变目录引用，进程扫描和匹配在锁外进行。

自动场景按同款游戏 ID 统计，每秒一次，至少 2 人且严格超过总人数一半持续 15 秒进入；失去条件持续 30 秒退出；换另一款多数游戏也需持续 15 秒。过期、未共享的活动不会计为游戏玩家，但成员仍在分母中。`server_state.room_scenes` 由服务器统一下发，观影覆盖显示但不停止后台场景判断。

本地 demo：先在 server 目录运行 `EDENVOICE_GAME_DEMO=1 EDENVOICE_DEMO_PASSWORD=Eden-demo-games-2026 go run ./cmd/admin-demo`，再在 desktop 目录运行 `node scripts/game-demo.mjs`，打开 http://127.0.0.1:9182 。模拟成员 / 观影，目录 API 和场景判定使用真实服务端实现，数据独立且仅监听回环。演示账号 admin；密码是上述演示值，与生产无关。点击快进模拟 15 / 30 秒；通过右上角进入真实管理页面编辑发布。
