# 独立共同观影窗口

客户端点击共同观影后打开 Tauri 原生窗口（720×600，可调整大小，最小 560×440）。固定 `watch-party` 标签，创建在 UI 线程串行执行；重复点击唤起既有窗口，最小化时恢复。入口为 `index.html?watch=1`。

独立页面订阅已有 Rust 核心的状态，不挂载完整 App，不创建第二条语音连接、音频引擎或通知循环。忽略与观影显示无关的说话指示及聊天快照变化。频道由当前自己的语音会话确定；切换频道或断线后不展示旧频道观影状态。

关闭原生窗口或页面右上角关闭按钮只关闭控制窗口，不发送退出观影或断开语音。明确点击“退出观影房间”才退出观影；“关闭观影房间”仍受主持人/管理员权限控制。关闭再打开会从核心恢复状态，影片仍由外部 mpv 播放。播放器设置可以在独立窗口内打开并返回。

验证：前端 TypeScript/Vite 构建通过；真实 React + 模拟原生桥的 Playwright 回归通过，覆盖窗口入口、关闭命令、设置返回、频道变化、断线、订阅清理和窄窗口，以及原有观影权限操作；Rust 桌面桥接 24 项测试通过。尚未进行 Windows 原生窗口实机验收。此变更需要重新构建/安装客户端，服务器无需升级。
