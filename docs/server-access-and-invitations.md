# 服务器密码与邀请链接

## 配置与兼容

在 TOML 顶层（所有 `[section]` 前）配置：

```toml
server_password = "SmileSion"
```

新部署使用的 `server/config.example.toml` 默认密码为 `SmileSion`；不提供配置文件启动时也使用此默认值。按需修改后重启服务端。最大 256 UTF-8 字节。

```toml
server_password = ""
```

空值表示无需服务器密码。**已有 TOML 未配置此字段也维持免密**，避免升级时意外改变现有访问方式。当前服务器对应的 `server/deploy/config.7000-7001.toml` 已显式设为空，本次没有部署或重启生产语音服务。

服务器密码与房间密码独立：前者在看到服务器成员、房间之前验证；后者控制进入具体房间。管理员和 MASTER 也需要服务器密码。

## 客户端流程

连接页新增“服务器密码”，免密时留空。先进行服务器身份确认，再经 TLS 在身份响应中发送密码。开启密码的服务器拒绝非安全协议访问。缺失、错误、限流都有独立提示，不进行后台无限重试。

密码只随当前连接保留在内存供断线重连，不写入服务器收藏、自动连接配置、导出备份或邀请链接。退出客户端后再次进入加密服务器需重新输入。记住服务器不等于记住密码。

旧版客户端仍可连接免密服务器；连接设有密码的服务器需要本次新版客户端。当前变更没有重新打包发行，不应覆盖 COS 上已发布的 v0.7.6 安装包。

## 邀请

在当前服务器菜单选择“复制服务器邀请链接”。格式：

```text
edenvoice://join?address=voice.example.com%3A7000
```

链接只含地址，不含昵称、密码或身份信任状态。应由用户自行分享给朋友。接收者安装新版后点击链接，客户端展示地址、昵称和可选密码，确认才连接。若已连接其他服务器，会明确说明将结束当前连接，并等待断开完成后再切换。取消不影响当前通话。

也可把链接直接粘贴进连接页的“服务器地址”输入框。拒绝携带密码、额外参数、重复参数、无效端口或其他 URL 协议的链接。

通过 Tauri 官方 deep-link 与 single-instance 插件注册 `edenvoice` 协议。Windows/Linux 已运行实例接收邀请；macOS 需要安装本次打包的应用以注册协议，开发模式无法完整模拟系统注册。运行时注册失败不阻断普通启动，可改用粘贴链接。

协议链接不依赖官网域名或 COS。部分聊天软件不将自定义协议变成可点击链接，可以复制完整文本并粘贴到客户端。

## 验证

- 真实 TLS 集成测试覆盖免密、正确密码、缺少密码、错误密码，验证认证前不发送 Welcome。
- 默认配置、旧 TOML、显式空密码与自定义密码回归。
- 邀请解析覆盖域名、IPv4/IPv6，以及恶意参数、重复参数和非法端口。
- 浏览器回归覆盖取消保留通话、确认后按顺序断开和连接、密码只随连接提交。
- 平台安装包的协议注册仍需打包后在对应系统验收。
