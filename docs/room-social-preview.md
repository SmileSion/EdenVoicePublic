# 房间互动预览

本次功能接入真实客户端与服务端，版本暂时保持 0.8.5。本地预览使用真实 App 组件与模拟控制连接，不会连接公开服务器，也不会发送到真实房间。

## 打开预览

在 `desktop` 目录运行 `npm run demo:room-social`，打开 `http://127.0.0.1:9199`。

- 顶部可切换明暗主题、4/16/40 人和房间。
- 点击“试贴一张截图”，或在消息输入框粘贴截图：先预览，确认后才发送。也可以点击输入框旁的图片按钮选图。
- 发出后点“查看聊天”，点击缩略图查看完整图片；Esc 返回。
- 点击“暂离”立即关闭麦克风并保留座位，不设置时长。点击“返回并开麦”或原来的麦克风按钮恢复；不会自动修改耳机开关。暂离和表情回应同步显示在左侧本房间成员行。
- “回应”提供六个表情，头像旁停留约 2.5 秒；没有显示座位的成员从侧边带昵称出现，最多三条。
- 点击“模拟静音说话”可预览本地提醒。实际客户端在主动静音下检测持续人声后提醒，用户自己决定是否开麦；暂离、耳机静音、管理员静音和按键说话未按住时不提醒。提醒 8 秒后关闭，可手动关闭，原生检测有 30 秒冷却。

预览内的战绩图为本地绘制的示例。所有模拟状态和图片只保留在当前浏览器页，刷新重置。

## 屏幕共享隐私暂停

另一个屏幕共享预览由 `node scripts/screen-share-demo.mjs` 启动，地址为 `http://127.0.0.1:9198`。可预览发布者暂停/恢复、朋友暂停中的观看页面以及明暗主题。

实际客户端在共享期间点击“隐私暂停”，会替换发送的画面并暂停共享声音，观众看到隐私占位页，包括暂停期间新加入的观众。语音通话保持独立；“恢复共享”沿用原来的共享源，无需重新选择。恢复失败时继续保护画面，用户也可直接结束共享。连接旧服务端时隐藏隐私暂停操作。

这项暂停与座位暂离是两个独立操作：座位暂离控制麦克风，共享隐私暂停控制共享画面及共享声音。

## 实际连接行为

完整使用需更新客户端与服务端。连接不支持这些能力的旧服务端时，客户端隐藏暂离/回应并禁用图片发送。新服务端只向主动启用房间互动的客户端发送新事件；旧客户端仍可正常语音聊天，收到图片消息时显示 `[图片]`。

暂离、回应和图片只作用于当前语音房间，大厅不启用。换房、断线或身份改变时清除本地状态并取消未完成的图片上传；离开后再进入同一个房间也不会继续旧上传。

截图支持 PNG/JPEG/WebP，发送前转换 JPEG，最长边不超过 1600 像素、压缩到 256 KiB 内。传输分块、限速并支持取消，聊天历史只保存图片引用。服务端图片保留 30 天，存储总量上限 64 MiB，达到上限后明确提示；历史引用可能显示图片已过期。详细协议和资源限制见 [room-social-protocol.md](room-social-protocol.md)。

## 验证范围

- 前端生产构建、控制器回归；真实组件浏览器交互覆盖取消/发送/看图、暂离/返回、左侧成员同步、回应过期、多人和窄窗口、明暗主题、换房与大厅隔离。静音提醒覆盖自动消失、手动关闭、新旧事件与换房清理。
- 原生协议及跨窗口事件的身份/房间隔离、ID 精度、同批次离开再进入的状态失效；持续暂离与麦克风同步。
- Go 完整测试和相关模块 race 检查；旧客户端兼容、持久化/过期、非法图片、限流。真实 TLS 同连接测试在图片读写阻塞时验证心跳、静音、取消和退房及时处理；同房取消立即结束原提交请求，退房再进入或断开后旧任务不回传图片/旧回复，额度在任务完成后释放。
- 本机五人真实 TLS 握手与加密 UDP 转发，并行图片上传下载和表情回应，所有预期语音包完整收到。使用合成载荷验证传输连续性，不代表公网听感或真实麦克风采集测试。
- 隐私暂停覆盖真实浏览器/WebRTC/SFU 画面和音轨、暂停期间加入、恢复不重选源、失败保持保护及旧服务端能力检测。

浏览器预览不覆盖 Windows/macOS 系统剪贴板与 WebView 的全部差异，发布前仍需在实际安装的客户端上确认系统截图粘贴。
