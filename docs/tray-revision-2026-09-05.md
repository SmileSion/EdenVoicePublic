# v0.6.8 系统托盘修订

- 启动时创建 EdenVoice 托盘图标。
- 完整窗口与小窗的最小化按钮隐藏到托盘；Windows 原生最小化也隐藏。
- 主窗口关闭按钮/系统关闭请求隐藏到托盘，语音连接与观影继续。
- 点击托盘图标或菜单“打开 EdenVoice”恢复、取消最小化并聚焦，保留原布局大小。
- 菜单“退出 EdenVoice”沿用现有 shutdown_and_wait，关闭音频、网络和本程序启动的 mpv。
- 托盘创建失败时保留普通最小化和关闭行为，不会隐藏成无法找回的窗口；关闭主窗口时同时关闭迷你悬浮窗。
- 用户启用的迷你语音悬浮窗仍独立运行。

只修改桌面端，不需要重启服务器。GitHub Actions 继续停用，使用本地 Windows x64 交叉构建。桌面 Rust 18 项回归与 TypeScript/Vite 构建通过；没有 Windows 真机托盘交互验收。

按用户要求更新 v0.6.8 Release 的 Windows 安装程序和 SHA256，发布说明记录修订提交；现有 Git 标签不移动。
