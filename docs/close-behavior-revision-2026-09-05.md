# 主窗口关闭行为

首次点击主窗口关闭按钮（含紧凑模式和 Windows Alt+F4），询问“最小化到托盘”还是“退出程序”。可取消，或勾选“不再提醒，将此选择设为默认行为”。不勾选时只执行本次选择。

设置 → 界面 → 关闭主窗口提供“每次询问 / 最小化到托盘 / 退出程序”，修改立即保存。偏好存放于 Tauri 本机配置目录的 window-close.json，默认每次询问；缺失、无效文件也回退为询问。保存使用临时文件替换，写入失败不更新内存偏好并显示错误。设置面板监听偏好更新，已打开的设置也会反映在关闭提示中记住的新选择。

原生关闭事件统一处理默认行为，并保存待处理请求供界面启动后恢复。重复关闭不会绕过已显示的选择窗口。退出复用已有语音、网络、mpv 清理路径；托盘菜单里的退出始终直接退出。最小化按钮维持收起到托盘行为。托盘不可用时不隐藏窗口，改为提示取消或退出。

新增界面回归覆盖取消、单次操作、记住选择、设置与同步更新、保存失败、启动时待处理请求、重复关闭及紧凑窗口。原生持久化回归覆盖缺失文件、默认值切换、重复写入、重读和损坏回退。

桌面 Rust 19 项测试、TypeScript/Vite 构建及关闭界面回归通过。Windows 包本地交叉编译，不使用 Actions；Windows 真机托盘、Alt+F4 和播放器退出仍需验收。仅桌面端改动，服务器无需部署。v0.6.8 标签不移动，Release 附件和修订源码链接更新。
