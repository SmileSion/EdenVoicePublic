# 轻量诊断、这一晚回顾、客户端版本

## 轻量诊断

入口在「网络详情」与设置的「语音诊断」。选择短暂停顿、电音、听不到声音或其他问题后点击记录。客户端原生后台每秒读取已有统计，内存保留此前最多 60 秒，记录后继续补充 10 秒；最多 61 个历史样本与一份有界报告，音频处理线程不参与采样和文件写入。隐藏窗口不会停止采样。

房间、服务器或连接会话变化时清空滚动历史，正在收集的报告提前完成并注明连接改变，避免把不同通话混在一起。重复记录在采集中被拒绝；完成后再次记录替换前一份。报告只在当前启动期间保存，用户可手动导出到下载目录或清除。不录音、不记录聊天、昵称、地址、身份、公钥或设备名称，也不自动上传。累计指标需要结合采样差值和时间判断，不能直接把欠载累计次数视作实际听感卡顿。

## 这一晚

房间全部离开超过原有 30 秒宽限期后，至少两位成员、持续至少两分钟且有语音或共同游戏/观影活动的相聚生成一条回顾。时长表示从房间本次首位加入到末位离开的跨度，不代表每个人全程参与或实际说话时长。卡片展示本次成员和实际记录的共同游戏、播放中的观影名称；最多各 8 个名称。观影至少需要两位已准备成员，文件路径只保留文件名。安静观影可留下回顾，但不会增加有效语音累计。

Archive 新增「这一晚」筛选，回顾卡片默认选择最近一次相聚，仍可选累计概览或原有事件。可隐藏活动名称、成员昵称或房间名称，预览与保存的 PNG 一致。旧记录不补造，正在进行的相聚不冒充已结束记录。服务器进程重启不会把停机期间算进一段持续相聚；尚未结束的会话摘要可能不保留。

## 后台版本

客户端 HELLO 通过可选字段上报构建版本和操作系统。每条会话分别保存，即使同一身份从不同客户端接入也不互相覆盖。后台连接列表和详情显示，并支持按版本搜索；旧客户端或非法上报值显示未知。元数据是客户端自报信息，不用作认证和权限判断。旧服务端忽略新增字段。

## 验证入口

- 服务端：`go test ./...`；`go test -race ./internal/archive ./internal/serverstate ./internal/control`。
- 客户端与桌面：两个 Cargo 项目的 `cargo test --lib`。
- 前端：`npm --prefix desktop run build`。
- 浏览器：`desktop/scripts/voice-incident.test.mjs`、`archive-recap.test.mjs`、`client-build-admin.test.mjs`。后台脚本使用隔离的 `admin-demo`；通过环境变量传入本机地址和演示密码。
