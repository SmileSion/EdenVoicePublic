# 共同观影：权限、使用流程与验收

## 本次解决的问题

原实现的服务端、桌面协调器和界面都只允许创建者关闭观影；同时，任何已就绪成员都能改变全员播放状态。本次改为用户确认的“主持人和管理员控制”，由服务器依据当前身份和频道权限裁决，客户端展示服务器下发的个人权限。

管理员必须在观影对应的语音频道中。结束观影和转交主持人无需加入观影、配置 mpv 或选择影片；控制全员播放需加入观影并加载本地影片。

| 操作 | 主持人 | 本频道管理员 / 服务器管理员 / MASTER | 普通成员 |
| --- | --- | --- | --- |
| 开启空房间、加入观影 | 可以 | 可以 | 可以 |
| 选择、更换本地影片、同步自己、退出 | 可以 | 可以 | 可以 |
| 全员播放、暂停、跳转 | 加入且播放器就绪后 | 加入且播放器就绪后 | 不可以 |
| 结束观影 | 可以 | 可以，无需加入观影 | 不可以 |
| 转交主持人 | 可以 | 可以，无需加入观影 | 不可以 |
| 调整自己音量、字幕、音轨 | 可以 | 可以 | 可以 |

其他频道的频道管理员不获得此房间权限。主持人转交给已加入观影的成员后，原主持人立即失去主持权限；如果原主持人同时是管理员，则保留管理员权限。服务端逐次检查角色，撤销管理员身份后，旧客户端状态不能绕过检查。

## 用户操作流程

1. 每个人安装 mpv，在播放器设置中配置可执行文件，并准备同版本影片。
2. 加入同一个语音频道，点击“共同观影”。第一人开启房间，其他人加入。
3. 选择各自的本地影片，启动 mpv；加载完成自动标记就绪。面板显示成员、影片名称、就绪人数和个人身份。
4. 主持人或管理员点击“一起播放”。有人未就绪或影片大小/时长不同，会提供继续等待或仍然播放的确认。文件检查不比较内容，不上传或分发视频。
5. 主持人或管理员可以在面板或自己的 mpv 中暂停、播放、跳转。普通成员只能影响本机，后续同步会恢复房间进度；“同步自己”会主动对齐，不改变别人。
6. 主持人可以选择成员并确认转交。结束房间需二次确认，所有观影成员退出，语音保持连接。

关闭面板继续观影；关闭播放器会变为未就绪，可重新打开影片。退出观影不退出语音；主持人离开后自动转交给剩余成员，最后一人离开时房间销毁。切换语音频道、断线会清理本机观影状态。

## 实现约束

- 新增频道作用域 `watch.manage`，以及 `watch_moderation_v1` 功能声明；`watch_state.permissions` 按接收者下发，不能把主持人权限广播给普通成员。
- `transfer_host` 仅接受当前观影成员的会话 ID。关闭和转交都检查房间 epoch，避免旧操作误伤重新开启的房间。
- 非参与管理员获得独立操作应答，不加入观影成员表或遗留限流条目；跨频道错误应答不泄露房间成员。
- 操作等待服务器确认期间禁用重复管理提交。权限不足等可恢复错误保留观影；房间失效才退出。影片元数据被拒绝后可重新选择，不会一直卡在加载状态。
- 普通成员的 mpv 播放变化不再生成全员控制指令。失去控制权限时清掉排队中的全员播放指令，保留本机同步。
- 观影沿用独立状态锁和有界播放器队列，不修改语音采集、DSP、媒体转发路径；视频不走语音服务器。
- 旧服务器保留主持人的播放/关闭能力，不推断管理员权限，也不显示转交功能。完整功能需要新服务端和新桌面客户端。

## 验证

- Go `go test -race ./...` 全部通过。新增角色矩阵覆盖 MASTER、服务器管理员、本频道管理员、其他频道管理员和普通成员；覆盖未入场关闭、越权控制、跨频道访问、过期 epoch、非法转交对象、逐人权限、角色撤销及状态清理。
- 桌面 Rust 24 项测试通过，包含 mpv 进程/IPC 回归，以及未入场管理员应答、主持权撤销、错误后保留成员、普通成员只能同步、旧协议兼容；最终防重复修改后再次通过全部观影协调器测试。
- 客户端全量回归 237 项通过、1 项既有长测默认忽略；新增权限协议测试后，3 项观影协议测试通过。
- 前端 TypeScript / Vite 构建通过。真实 React + 浏览器回归通过，原生桥为明确 mock；覆盖文件重开、准备提示、权限按钮、转交、未加入管理员关闭、普通成员同步、旧服务端入口、深浅主题和 390px 窄屏。
- 公网 `voice-smoke -watch-check` 通过：TLS 1.3、原服务器身份验证、双向加密 UDP 载荷、加入/就绪/播放同步、普通成员越权拒绝、主持人显式转交与权限收回、离开自动转交、关闭/重开。

浏览器回归不等同于 Windows/macOS 实际多人看片听感测试；公网烟测验证协议和媒体载荷，未做真实影片、多地域多人音频听感评测。
