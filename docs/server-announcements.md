# 服务器公告

后台「服务器公告」支持编辑草稿、预览并发布、撤回。草稿不会影响客户端；正在发布的相同内容重复发布不会产生新版本。标题最多 80 字，正文最多 3000 字，以纯文本展示、支持换行和复制。发布前使用版本校验防止覆盖其他管理员的编辑，只读账号不可修改。

在线客户端通过服务器状态快照接收最新公告；重连时同样读取当前最新公告，不补弹历史。点击「知道了」、关闭按钮或 Escape 都会保存已读版本。记录按服务器指纹与本机客户端身份隔离，关闭并重新打开客户端后继续有效。换设备、重建身份或清理本地数据后可能再次看到当前公告。保存失败时会明确提示，不会假装已持久化。

新公告替换当前弹框，不堆叠。撤回后移除尚未关闭的弹框。公告没有提示音，不改变语音房间、音频或屏幕共享连接。明暗主题均适配，长正文支持滚动和复制。

服务端保存在数据目录 `announcements.json`，采用临时文件与原子替换；只有成功写入后才更新内存并广播。新增可选快照字段兼容旧客户端，但公告弹框需要升级客户端和服务端后才生效。

- 服务端 `go test ./...`：存储重启、幂等发布、草稿隔离、最新替换、撤回广播、权限、CSRF、过期编辑冲突、语音房间不变。
- Rust 客户端库 291 项通过、2 项原有忽略；桌面库 35 项通过。
- 前端 `npm run build` 通过。
- `desktop/scripts/announcements.test.mjs`：真实 React 弹框模拟最新替换、旧版本忽略、已读刷新与重连、服务器隔离、撤回、Escape、纯文本、小窗口长公告；明暗主题截图已检查。
- `desktop/scripts/announcements-admin.test.mjs`：本机隔离演示后台登录、保存草稿、预览发布、页面刷新和撤回。

浏览器测试通过 `PLAYWRIGHT_MODULE` 和可选 `CHROME_EXECUTABLE` 指定本机测试依赖；后台测试需要独立运行 `server/cmd/admin-demo` 并设置 `EDENVOICE_DEMO_PASSWORD` / `EDENVOICE_DEMO_URL`。这些为模拟与本机测试，不代表已在生产发布。

补充校验：发布与撤回均携带状态版本号，Rust 状态层和前端均拒绝迟到的旧快照，防止撤回后旧公告复现或新公告被旧撤回覆盖。补充了身份隔离、存储写入失败及新公告重置错误提示测试。
