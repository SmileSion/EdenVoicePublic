# 日常功能补齐

- 个人音量按服务器地址、服务器指纹和成员 Client ID 持久化；重新上线时映射到新的 Session ID。滑杆调整立即影响播放，配置写入延后 500ms 合并，退出时保存。
- 设置 → 关于提供检查更新；启动 15 秒后检查服务器下发的 COS 更新信息，随后每分钟检查。用户确认后下载，可立即安装或下次启动安装；通话中安装须再次确认。网络不可达静默处理。签名与发布要求见 automatic-updates-2026-09-08.md。
- 创建房间可设置密码；编辑可保留、修改或取消密码。密码通过现有控制连接发送，服务端使用 bcrypt 散列保存，公开状态只有加锁房间 ID。旧服务器不支持时禁止设置，避免误认为已加密。
- 加密房间加入前弹出密码框，错误可重试；普通 join 请求不能绕过校验。管理员主动移动成员仍按既有管理权限执行。连接期间密码只保存在内存中用于断线恢复，不写客户端磁盘。

验证：前端构建、原生 cargo check、配置持久化单测、服务端密码校验/权限/持久化测试和浏览器密码重试/更新入口测试。当时的私人部署记录已移除；客户端安装包见 dist/v0.7.6。
