# EdenVoice 客户端 0.8.1

本次发布仅更新 Windows 客户端，兼容现有 0.8.0 服务端；无需更新语音服务器。其他平台及服务端下载继续保留 0.8.0。

## 语音连续性

- 语音检测使用开启、维持两个阈值：RMS 0.004（约 -48 dBFS）开启，已开启时 RMS 0.002（约 -54 dBFS）维持。低于维持阈值后保留 400 ms 尾音；保护期内再次检测到有效语音会刷新完整保护期。开启阈值不随之降低。
- 开口前保留最多 60 ms 采集帧，减少弱辅音丢失；按键说话按采集时的按键状态决定发送，实时静音仍然优先。
- 短暂接收间隙不立即重新预缓冲；新一句话的起始帧避免时间伸缩，低相关波形不强行拼接。
- 音频处理器切换期间，以混合后的实际音频计算电平，并保留任一处理器检测到的语音。
- 正常句间停顿不再计入确定的缓冲耗尽；收到后续时间戳证明确实缺失音频才计数。
- 不修改音量默认值。

## 验证

- 客户端核心测试：287 通过，2 忽略，0 失败。
- 桌面后端测试：32 通过，0 失败；前端生产构建通过。
- 双阈值回归覆盖弱音维持、关闭后不能由弱音重新开启、保护期内恢复说话、低电平背景噪声释放。
- 实际 Opus 编解码的 72 次中文双字开口模拟，覆盖 40/80/120/200/400/800 ms 句间停顿：未出现模拟器判定的有效语音输出空洞或确定缓冲耗尽。

这些是自动化与跨平台构建验证，不等同于 Windows 实机、真实网络和不同麦克风下的听感验收。

## Windows 发布

产物目录：`dist/v0.8.1/windows/`。安装包为 `EdenVoice_0.8.1_x64-setup.exe`，相邻 `.sig` 为现有客户端公钥对应的 Tauri 更新签名，不是 Windows Authenticode 签名。

COS 对象路径：`releases/v0.8.1/EdenVoice_0.8.1_x64-setup.exe`。产品页从 `releases.json` 读取此地址；管理员更新 JSON 使用相同地址。用户上传完成并确认链接可访问后，再在管理后台确认下发 Windows 更新。

产品页通过 `versions` 分别显示各平台版本，避免把仍为 0.8.0 的服务端标记为 0.8.1。本次不自动下发客户端更新，也不部署语音服务器。
