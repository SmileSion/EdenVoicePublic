# EdenVoice v0.7.7

客户端、桌面安装包配置与服务端程序版本统一为 0.7.7。服务端支持 `voice-server --version`，启动日志包含版本号。

本版包含按房间索引语音接收者、来源验证减少复制、出站缓冲复用，以及客户端快照增量刷新和显式静音 WebRTC 优化。实现、自测及收益边界见 [性能优化说明](performance-optimizations-2026-09-09.md)。

服务端可独立升级，兼容 v0.7.6 客户端；客户端优化需安装新客户端后生效。本次服务端部署保留现有配置、身份、房间和持久化数据，不发布管理后台的客户端更新通知。产品页下载地址继续指向实际已有的 v0.7.6 COS 安装包，待新包上传后再更新链接。

版本变更后再次通过服务端全包测试、go vet、Linux AMD64 静态编译、桌面前端构建和 Windows 发布配置检查。该版本原先配置了 tag 触发的 GitHub Actions 构建；此机制已移除，当前使用本地发布脚本。打包完成不等于 COS 安装包已上传或客户端更新已发布。
