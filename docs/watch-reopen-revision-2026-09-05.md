# 观影面板与重新打开影片修订

关闭 mpv 后，观影成员仍留在房间。本次修订在原生协调器内保留本机影片路径，提供“重新打开影片”，不再要求重复选择文件。关闭再打开面板仍能恢复文件名及操作；切换服务器、语音房间、会话或断线时清除记忆。路径仅保存在本次进程的内存中，不发送给其他成员。

重新打开复用已有加载与同步流程：mpv 报告有效文件信息、服务端确认该成员的当前文件就绪后，才显示已就绪并同步房间进度。已有播放器运行时忽略重复的重新打开命令。影片被移动或播放器启动失败时保留错误提示，可重新打开或更换影片。

观影界面使用影片卡片、成员侧栏、明确的播放/重新打开/更换操作；适配窄窗口、浅色与系统主题，并限制键盘 Tab 在对话框内移动。各成员文件名、就绪状态和房主身份独立展示。

目前影片一致性检查是文件大小及相差不超过一秒的时长比较，不做文件内容哈希；不同文件名也可能是相同影片，大小及时间相同也不能证明内容相同。差异仅提示，不阻止播放。

验证：桌面 Rust 18 项测试、TypeScript/Vite 构建及模拟原生桥接的浏览器交互测试通过。界面测试覆盖重新打开命令、不重复调用文件选择、面板重开、文件差异、成员列表、房间关闭/退出、旧服务端禁用、深浅色和窄屏布局。Windows 包为 macOS 本地交叉构建，Windows 真机 mpv 交互仍需验收。

仅修改桌面程序，协议和服务器无需变更。继续更新现有 v0.6.8 Release 附件，标签保持原有提交，Release 说明链接修订源码。GitHub Actions 保持停用。
