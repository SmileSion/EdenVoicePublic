# v0.6.8 观影修订交付

> 后续权限与交互已调整，当前行为见 [2026-09-07 观影权限修订](watch-party-moderation-2026-09-07.md)。

## 行为

- 播放器路径移至设置 → 播放器。选择后验证并等待磁盘保存，成功提示下次无需重复选择；写入失败明确报错。手工输入需点击播放器设置自己的保存按钮，保存立即生效。
- 观影房间与影片分开：开启/加入 → 选择本地影片 → 就绪 → 播放。允许在房间内重新选择影片；播放器退出或失败后保留房间与文件名，便于重试。
- 所选文件名在启动期间和失败后保留，播放器加载、就绪、暂停、错误有独立反馈。
- 开房者为房主，房主可以关闭整个观影房间；其他成员只能退出。房主退出后移交给剩余成员中 session ID 最小者。最后一人退出销毁房间，重新开启采用新 epoch。
- 关闭观影面板不退出；关闭观影房间、播放器或退出观影均不退出语音房间。

## Windows 闪退原因

当前 Rust 1.95 的 Windows `File::read` 将 ERROR_NO_DATA 映射为 BrokenPipe，再转换为 Ok(0)。非阻塞命名管道暂时空闲时可能走到这个分支。旧版把零字节当作永久断开，结束播放器工作线程并清理其拥有的 mpv 子进程。

现改为 Windows 零字节读取等待下一轮，以真实子进程退出和有界 IPC 超时判断失联。同时规范化 Windows 影片路径（包括 UNC），强制打开窗口，捕获最多 4KB 的本地 stderr 尾部，报告加载失败、启动退出码、控制连接及响应超时。
