EDENVOICE / GET CLOSER

从第一次连接，开始相聚。

给第一次使用 EdenVoice 的你。先完成语音连接，再按需要探索观影、游戏和房间记忆。

本文介绍 v0.8.5 功能。下载区会标明各平台已发布安装包的实际版本，较早的客户端可能没有全部入口。

01 / 准备客户端

选择与你电脑相符的版本。

在下载区选择 Windows x64、macOS Apple Silicon 或 Linux x64。macOS 包适用于 M 系列芯片，当前没有提供 Intel Mac 包；Linux 客户端以 AppImage 提供。

Windows 运行安装程序；macOS 打开 DMG 并将应用放入“应用程序”；Linux 为 AppImage 添加执行权限后运行。系统如果提示发行者信息，请先确认安装包来自本页链接，不要关闭整台电脑的安全保护。

02 / 找到你们的空间

一个地址，把朋友聚在一起。

  1. 向朋友获取 EdenVoice 服务器地址，通常是“主机名或 IP:端口”。
  2. 打开客户端，填写服务器地址与昵称，或使用朋友提供的邀请链接填入连接信息。服务器启用密码时，按提示输入密码再连接。
  3. 首次连接时确认服务器身份；如果熟悉的服务器身份发生变化，先向管理员核实。

请向朋友或服务器管理员获取连接地址。本网站不提供公共体验服务器。

此时你只是在线，还没有进入语音。一个人部署服务器即可，其他朋友只需要客户端；无需每个人都搭建服务器。

03 / 开始第一句对话

加入同一个房间，才能听见彼此。

  1. 在左侧频道列表双击想加入的语音房间。需要密码时，输入管理员提供的房间密码。
  2. 检查底部麦克风和耳机状态，确认没有静音。
  3. 在音频设置中选择正确的输入、输出设备，用本地自听检查自己的声音。

某位朋友的声音太响或太轻，可以单独调整他的个人音量，下次连接同一服务器时继续沿用。聊天消息可选中复制；房间气泡会淡出，长消息可以跳到聊天区域查看完整内容。

连不上或听不到声音？ ↗
一起看一场电影

准备各自的影片，同步同一段进度。

  1. 每个人安装 mpv，在客户端“设置 → 播放器”选择可执行文件。Windows 选择 mpv.exe，macOS 可选择 mpv.app。
  2. 大家准备同版本的本地影片。观影功能不上传或分发影片。
  3. 在语音房间点击“开启共同观影”并确认。开启者成为主持人，其他成员自行加入。
  4. 各自选择本地影片，确认就绪；主持人或有权限的管理员控制全员播放、暂停与跳转。
  5. 普通成员可以同步自己或退出。结束全员观影由主持人或有权限的管理员确认执行，语音通话继续。

影片大小或时长不同会提示检查版本。房间同步播放状态，视频由每个人的本地 mpv 播放。再次选择匹配的影片，主持人看到“上次看到”的提示后，可以恢复全员进度，也可以暂不恢复。

一边聊天，一边看看你的屏幕

在当前房间，打开“屏幕共享”。

  1. 加入语音房间，切换到“屏幕共享”标签。需要服务器已开启此功能，并使用支持屏幕共享的客户端。
  2. 点击“分享屏幕”，选择分辨率、帧率和码率，再在系统选择器中确认要共享的画面。
  3. macOS 使用系统的统一选择器；共享整个桌面时，选择“共享整个屏幕”。Windows 可从整个桌面或程序窗口开始选择，最终以系统授权的画面为准。
  4. 同房间的朋友点击“观看”加入。画面嵌在当前客户端里，随窗口变化；想看细节时，可以点击“全屏”。
  5. 切回房间或聊天标签会保留观看连接。观看者点击“停止观看”离开，分享者点击“结束共享”结束；有权限的管理员也能结束共享。

每个房间同一时刻一人共享，多个房间可以分别进行，受服务器并发上限约束。跨房间不能直接观看；离开房间会结束自己的共享或观看连接。

共享声音是可选项，支持情况受系统和采集方式影响。共享系统声音可能包含通话声，使用前请留意回声；麦克风交流仍走原有语音通话。

屏幕共享是持续传输画面；共同观影只同步各自本地影片的进度。观看同一部本地电影时，可选择更节省服务器视频带宽的共同观影。

让朋友知道你在玩什么

分享游戏状态，房间随大家变化。

Windows 客户端默认开启游戏状态分享。启动服务器目录中支持的游戏后，可以在成员列表看到游戏名称；没有有效状态时显示“在线”。

在“设置 → 个人资料 → 共享正在玩的游戏”可关闭，关闭后撤回当前分享。其他平台可以查看朋友的状态，但当前不提供 Windows 游戏进程识别。

同房间过半成员玩同款游戏时，房间会自动进入对应游戏模式。这个展示不会帮你启动游戏或匹配队伍。

给手头的事一点专注

从标题栏，打开小小番茄钟。

点击计时图标，添加带自定义名称的计时。可以正向计时，也可以使用默认 30 分钟倒计时或自定义到秒的时长。

最多保存 10 个计时，通过左右翻动与底部圆点切换；悬停圆点可以查看名称。一次只能运行一个计时。倒计时结束会在本客户端轻响提醒，正向计时不提醒。

翻阅房间留下的痕迹

在房间菜单中，查看 Eden Archive。

  1. 连接已开启 Eden Archive 的服务器。
  2. 右键房间，选择“查看 Eden Archive”。
  3. 查看房间统计与 Memory Timeline，按“全部”“这一晚”“一起玩”“房间时刻”筛选。可搜索游戏、朋友或回忆内容；“一起玩”还可选择具体游戏。

统计包含创建至今、活跃天数、有效语音、曾来过的人与最长会话。符合规则的参与和时间状态会形成记忆节点，时间线展示日期、描述及参与者。游戏专属卡片包含游戏名称、时长、参与伙伴的头像与昵称；人数较多时可以展开。筛选范围是当前已加载的记录。

点击“制作回顾卡片”，可以选择某段回忆或房间概览，决定是否显示游戏与观影名称、房间名称、成员昵称，再保存成图片。活动要达到服务器的记录条件才会出现；整晚回顾在这次相聚结束后生成，不代表游戏战绩或电影内容记录。

如果没有入口，先检查“设置 → 界面 → Eden Archive”是否开启；也可能是服务器没有启用该功能。这个客户端开关只隐藏或显示入口，不会关闭服务器收集。Archive 不录制语音，也不是录音回放或语音转写。

让习惯跟着你

设置头像，妥善保管自己的身份。

在“设置 → 个人资料”修改昵称、上传头像。客户端身份在本机生成，用于服务器识别你；昵称和身份并不是同一回事。

换电脑前，可在个人资料的数据迁移区域导出加密备份，并在新设备导入。保管备份与密码，避免删除身份后失去原有服务器身份关联。

新版本由当前服务器的管理员发布后，客户端提醒你更新。确认下载后，可选择立即安装重启或下次启动更新。

为朋友准备一个常驻空间

先接通语音，再按需要开启画面。

下载适合服务器 CPU 的服务端，按包内 README 使用配置文件启动。默认控制连接为 9000/TCP、语音为 9001/UDP；云安全组与主机防火墙需要放行你实际配置的端口。管理后台默认只监听本机，可通过 SSH 隧道访问。

从 v0.8.5 开始，屏幕共享使用独立的单个固定 UDP 端口，默认 7010/UDP，无需开放整段端口范围。在 TOML 中配置并重启服务端：

[screen_share]
enabled = true
udp_port = 7010
# 云服务器有公网映射时，填写你自己的公网 IP
public_ip = ""

在安全组与主机防火墙放行这个 UDP 端口，存在端口映射时也需映射同一个端口。屏幕共享转发需要额外出口带宽；从后台设置画质、观看人数和并发房间上限，再用朋友实际使用的网络验证。

请修改新部署服务端的默认服务器密码，妥善保存管理账号、身份与数据目录。升级时保留现有配置和数据，不要用示例覆盖。下载区的服务端压缩包版本可能较早：单端口配置需运行 v0.8.5 或更高版本，旧版不能通过仅修改端口字段获得该能力。
