为总会再见面的那群人

不是每次上线，
都要有一件正事。

有时候只是想听见朋友的声音。有人打游戏，有人写东西，有人刚下班。EdenVoice 想做的，是让你们有一个可以随时回来、舒服待着的地方。

01 / 找到人

不必先问一句“在哪儿”。

打开大厅，看看谁在线、谁在哪个房间。Windows 成员分享游戏状态后，还能看到朋友在玩什么。选一个房间加入，才真正接通彼此的声音。

02 / 待得住

各做各的，也有陪伴。

把主窗口收进托盘，用小悬浮窗看看谁在说话。朋友的个人音量会被记住；你可以把注意力留给游戏、工作，或眼前的事。

03 / 有自己的地方

房间和规则，都由你们定。

连接朋友搭好的服务器就能使用；也可以自己部署，创建日常聊天、开黑或需要密码的房间。熟悉的小圈子，有自己的相聚方式。

如果你想要的是：固定朋友、常驻房间、语音优先。

EdenVoice 值得试一试。它更适合已经认识的人一起使用；初次加入时，你需要一个服务器地址，请向朋友或服务器管理员获取。

按环境选择降噪、回声消除与输入增益，用本地自听找到舒服的听感。

为每个人记住

熟悉的声音，熟悉的音量。

有的朋友麦克风响，有的说话轻。单独调整每个人的音量，不改变其他人的听感；下次连接同一服务器时，继续沿用。

实际音质与延迟受设备、网络和音频设置影响。

20:30 / 先聊几句

打开房间，就是熟悉的朋友。

成员头像和发言状态放在房间里。暂时不方便开口，就打几个字：消息会出现在头像上方，十秒后淡出。长消息可以点开查看完整内容，文字也能选中复制。

大厅只展示在线状态，加入语音房间后才能听见彼此；人多时会收拢展示，并提供完整成员列表。

21:00 / 一起开一局

游戏是主角，交流跟得上。

Windows 客户端识别管理员配置过的游戏，在成员列表展示状态。当同一房间过半成员正在玩同款游戏，房间自动变成游戏场景，无需手动切模式。

游戏状态默认分享，可以在设置中关闭。识别范围由服务器目录决定；未识别到有效游戏时，成员列表显示“在线”。

22:30 / 留一场电影的时间

暂停一下，大家真的一起等。

在当前房间开启共同观影，邀请朋友加入。每个人选择自己的本地影片，准备好后由主持人开始播放；暂停和跳转也同步给全员。不参加观影的人，仍可以留在语音里聊天。

主持人与有权限的管理员可以结束全员观影；普通成员退出只影响自己。结束后回到日常房间，语音通话继续。再次选择匹配的影片时，主持人还可恢复上次的全员进度。

01 / 你来分享

一个窗口，或整个桌面。

想演示一段操作、一起看一份攻略，就从房间里分享屏幕。选择画面，再按需要调整分辨率、帧率与码率；服务器会设定可用上限。

02 / 朋友加入

点“观看”，才接收画面。

共享入口只对同一个语音房间的成员开放。想看的人自行加入；每个房间同一时刻由一人分享，不同房间可以分别共享。

03 / 留在房间

嵌入观看，也能全屏。

画面放在房间的“屏幕共享”标签中，随窗口调整大小。可以全屏看细节，也能切回房间或聊天；停止观看、结束共享都有明确入口。

第一次分享屏幕 ↗

需要支持该功能的新版客户端与已开启屏幕共享的服务器。采集与共享声音的支持范围取决于操作系统。

01 Web 管理后台 +

使用账号密码登录 Web 管理后台，查看资源占用、性能和连接情况，管理房间与成员。不必为了日常维护反复编辑配置文件；游戏识别目录和不同平台的更新版本，也可以从后台维护与发布。

02 服务器密码、邀请与分级权限 +

可以为整个服务器或单独房间设置进入密码，用邀请链接帮助朋友填写连接信息。主持人、频道管理员和服务器管理员各有清晰的操作边界。

03 自己的身份与连接 +

客户端本地生成设备身份，无需注册平台账号。语音支持 SFU 转发与 P2P 直连，可按房间设置网络策略。

自己部署，意味着你掌握空间，也负责照顾它。

准备一台可访问的服务器，配置网络与服务端，保管数据和管理账号。只想和朋友聊天？安装客户端，连接他们已搭好的服务器即可，不需要每个人都部署一份。
